# E-Commerce System – Microsoft Dynamics 365 Finance & Operations

## Overview

This project is an E-Commerce application developed within **Microsoft Dynamics 365 Finance & Operations (D365 F&O)** as a practical implementation of integrating e-commerce functionalities into an ERP environment.

The main goal is to explore how an ERP system can support e-commerce operations by managing products, customers, and business transactions within a unified platform.

The project demonstrates the practical application of D365 F&O development concepts and provides hands-on experience with extending ERP functionalities.

## Project Objectives

- Build an E-Commerce application inside Microsoft Dynamics 365 F&O.
- Understand how to extend standard ERP functionalities.
- Apply X++ development concepts in a practical business scenario.
- Explore data management and business logic within D365 F&O.
- Connect e-commerce operations with ERP business processes.

## Development Environment

The project was developed using a local Microsoft Dynamics 365 Finance & Operations OneBox environment.

Development workflow:

2. Developing custom objects using X++.
3. Designing forms and user interfaces.
4. Implementing business logic.
